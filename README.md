# Python Phase 2: Functions, Data Structures & AI Mini-Projects

A collection of hands-on Python scripts and mini-projects focused on mastering functions, default arguments, lists, and building foundational logic for AI engineering workflows.

## Repository Contents

| File Name | Description | Key Concepts |
| :--- | :--- | :--- |
| `DefaultArguments.py` | Practice scripts demonstrating function definitions with default parameters. | Functions, Default Arguments |
| `DefaultArguments-2.py` | Extended exercises exploring parameter ordering and flexible function calls. | Function Signatures, Overriding Defaults |
| `Dynamic_Student_Info_Generator.py` | A dynamic utility script to format and generate structured student records. | String Formatting, Dynamic Inputs |
| `list.py` | Core exercises covering Python list operations, indexing, and manipulation. | Lists, Iteration, Data Manipulation |
| `Smart_AI_Model_Token_&_Cost_Estimator.py` | Estimates token usage and calculates API cost based on prompt input. | Arithmetic Logic, Function Modularity |
| `mini_project_Smart_AI_Tool_Configurator_&_Va...` | Mini-project for configuring and validating parameters for AI tools. | Input Validation, Conditional Logic |

## Key Concepts Covered

- **Modular Functions:** Writing reusable functions with positional and default arguments.
- **Data Structures:** Working with Python lists to store, access, and transform data.
- **Validation & Logic:** Implementing input checks and structured configuration logic.
- **AI Engineering Foundations:** Simulating token estimation, cost calculation, and tool validation workflows.
